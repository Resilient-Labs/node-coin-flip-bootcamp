## Project Overview

Coin Flip Game is an application where users can bet against the server to see whether the result of a coin flip will be heads or tails.

## Features

- Choose heads or tails for bet.
- Click button to generate result.

## Installation

1. Clone the repository:

```bash
git clone https://github.com/yourusername/Coin-Flip-Game.git
````

2. Navigate to the project directory:

```bash
cd coin-flip-game
```

3. Open Project File

4. Use in browser
   
## Usage

1. Use dropdown menu to select choice for bet.
2. Click submission button to see result of flip.

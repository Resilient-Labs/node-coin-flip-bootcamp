# Coin Flip Royale 💜 👑

Bet your pride on **Heads or Tails**, hit **Toss Coin**, and watch the magic unfold. Do you win gold… or walk away broke in the neon night?

---

## ✨ Features
- 🪙 Server-side randomness for every flip (no cheating here!)  
- 🏆 Real-time win/lose logic displayed instantly  
- 🎨 Vibrant **Vegas-style UI** — glowing gold and royal purple 
- 💥 Simple, fast, and 100% browser-based  
- 🃏 Perfect for practicing your luck (or coding karma)

---

## 🛠️ Tech Stack
- **Node.js** – backend logic & server creation  
- **HTML5** – structure  
- **CSS3** – flashy casino styling  
- **JavaScript** – client interactivity & fetch logic  
- **figlet** – stylized 404 ASCII art  

---
## 🧠 How It Works
- Choose Heads or Tails.
- Click Toss Coin.
- The server generates a random outcome (heads or tails).
- The result flashes in royal gold. 

---

## 📦 Installation & Setup
1. Clone this repository:
     
```bash
git clone https://github.com/your-username/node-coin-flip.git
  ```
2. Navigate into the project folder:

```bash
cd node-coin-flip
  ```
3. Install dependencies:
   
```bash
npm install figlet
  ```  

4. Start the server:
   
```bash
node server.js
  ```

5. Open your browser.

```bash
http://localhost:8000
```

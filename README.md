# Node Coin Flip Game

This project is a game of 50/50 coin flip! Click the button, and you get heads or tails! 

## How It's Made:

**Tech used:**: HTML, CSS, Javascript, and NodeJS!

I used html for the markup, css for the styling, and I used Javascript for getting the clients input, and NodeJS for the logic of this project.

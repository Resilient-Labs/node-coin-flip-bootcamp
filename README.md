# Coin Flip Game

The Coin Flip Game is a simple web application that allows users to play a heads or tails guessing game. Users choose either heads or tails, flip a virtual coin, and see whether their guess matches the result.

This project uses Node.js to run a local server and serves an HTML page where users can interact with the game. The application features a simple, straightforward interface without a specific theme.

## Features
User Choice: Select heads or tails before flipping the coin.
Coin Flip: Generate a random coin flip result.
Guess Validation: Check whether the user's guess matches the coin flip.
Game Results: Display whether the user wins or loses.
Simple Interface: Use HTML, CSS, and JavaScript to create an easy-to-use experience.

## Tech Stack
Frontend: HTML, CSS, JavaScript (ES6)
Backend: Node.js

## Installation
Fork and clone the repository.
Navigate to the project directory.

## Usage
Start the server using:
node server.js

Open your browser and navigate to:
http://localhost:8000

Choose either heads or tails.
Flip the coin.
See whether your guess was correct!
